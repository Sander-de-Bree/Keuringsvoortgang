# Keuringsvoortgang

Een compacte, Nederlandstalige statusdashboard voor keuringen op project GIGA Leopard.

## Starten

Open `index.html` in een moderne browser. Er is geen buildstap of server nodig.

## Mogelijkheden

- Voortgangssamenvatting met totalen, lopende keuringen, goedkeuringen en afkeuringen.
- Keuringen gegroepeerd per sectie, met zoeken en filteren op status.
- Status direct aanpassen en keuringen toevoegen.
- Gegevens worden bewaard in `localStorage` van de huidige browser.

De meegeleverde keuringen zijn voorbeeldgegevens. De gegevens zijn lokaal per browser en worden niet gedeeld met andere gebruikers of apparaten. Voor gezamenlijk gebruik is een backend of gedeelde databron nodig.
